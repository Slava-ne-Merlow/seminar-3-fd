## 1. Книга

Конструктор: `Book(id: Int, title: String, author: String, genre: Genre = Genre.FANTASY)`.

`id`, `title`, `author`, `genre` — свойства `val`. В `init` через `require` проверьте: `id > 0`, название и автор не пустые и не состоят только из пробельных символов. Для строк используйте `isNotBlank()`. Корректные строки сохраняйте без изменений. Писать обработку исключений не нужно: при неверных данных `require` сам останавливает создание объекта.

Свойство `isAvailable: Boolean` изначально равно `true`. Читать его можно снаружи, изменять — только внутри `Book`: используйте `private set`.

- `borrow(): Boolean` — для доступной книги устанавливает `isAvailable = false` и возвращает `true`. Если книга уже выдана — `false` без изменений.
- `returnToLibrary(): Boolean` — для выданной книги устанавливает `isAvailable = true` и возвращает `true`. Если книга уже доступна — `false` без изменений.

Состояния разных экземпляров независимы.

## 2. Карточка книги

Создайте `data class BookInfo` с тремя свойствами `val` в первичном конструкторе, в таком порядке: `title: String`, `author: String`, `genre: Genre`. Карточки с одинаковыми данными должны быть равны через `==`.

После создания `BookInfo` самостоятельно добавьте в `Book` метод `fun info(): BookInfo`. Он возвращает карточку с названием, автором и жанром этой книги, не меняя её состояние.

## 3. Жанры и правила выдачи

Готовый `enum class Genre` содержит `FANTASY` («Фэнтези»), `ADVENTURE` («Приключения»), `SCIENCE` («Наука»). Поле `label` хранит русское название.

В общем объекте `LibraryRules` реализуйте `loanDays(genre: Genre): Int`: `FANTASY` — 21 день, `ADVENTURE` — 14, `SCIENCE` — 7. Используйте `when` как выражение и перечислите все варианты без `else`.

Даты, штрафы и учёт читателей не нужны.

## 4. Уведомления

Готовый интерфейс `Notifier` объявляет `send(message: String)` без возвращаемого значения. Создайте две реализации с конструкторами без аргументов:

- `ConsoleNotifier` — печатает переданное сообщение и перевод строки. Без дополнительных подписей.
- `CountingNotifier` — считает отправленные сообщения и запоминает последнее. Свойства `sentCount: Int` и `lastMessage: String` изначально равны `0` и `""`. После каждого `send` счётчик увеличивается на один, а последнее сообщение заменяется переданным. Пустые строки и повторы тоже считаются сообщениями. У обоих свойств — `private set`; каждый экземпляр хранит собственное состояние.

## 5. Библиотека

Конструктор уже задан: `Library(books: Array<Book>, notifier: Notifier)`. Он получает готовый массив книг и объект уведомлений. Добавлять и удалять книги не нужно.

В массиве нет одинаковых `id`. Разные книги могут иметь одинаковые названия и авторов. Книга может быть выдана ещё до создания библиотеки; её состояние нужно сохранить. Массив и состояние книг после создания библиотеки снаружи не меняют. Один экземпляр книги не передаётся в разные библиотеки.

Библиотека работает с переданными объектами книг. Для выдачи и возврата вызывайте методы `Book`. `Notifier` может иметь любую реализацию: не создавайте свой уведомитель вместо переданного и не проверяйте его конкретный тип.

### Наличие книги

`hasBook(id: Int): Boolean`

Возвращает `true`, если в библиотеке есть книга с таким `id`, включая выданные книги. Иначе — `false`.

### Выдача

`borrowBook(id: Int): Boolean`

Выдаёт найденную книгу через её метод `borrow()`. При успехе возвращает `true` и ровно один раз отправляет сообщение `Выдана книга: <название>`. При отсутствии книги или повторной выдаче возвращает `false`, ничего не меняет и не отправляет сообщений.

### Возврат

`returnBook(id: Int): Boolean`

Возвращает найденную книгу через её метод `returnToLibrary()`. При успехе возвращает `true` и ровно один раз отправляет сообщение `Возвращена книга: <название>`. При отсутствии книги или возврате уже доступной книги возвращает `false`, ничего не меняет и не отправляет сообщений.

Для выдачи и возврата состояние книги должно измениться до отправки уведомления. Нулевой или отрицательный `id` означает, что книга не найдена.

### Количество доступных книг

`availableCount(): Int`

Возвращает количество книг, доступных в данный момент. Для пустой библиотеки — `0`.

### Количество книг выбранного жанра

`countByGenre(genre: Genre): Int`

Возвращает количество всех книг указанного жанра, включая выданные. Если подходящих книг нет — `0`.

### Отчёт

`report(): String`

Возвращает информацию обо всех книгах в порядке их расположения в массиве. Каждая книга — на отдельной строке:

```text
7. Хоббит — Джон Толкин: выдана
2. Маленький принц — Антуан де Сент-Экзюпери: доступна
```

Число перед названием — `id`, а не позиция. Статус — строго `доступна` или `выдана`. Разделитель строк — `\n`, без переноса в конце. Для пустой библиотеки верните `Библиотека пуста`. Соберите строку обычным циклом и сложением строк.

Проверка наличия, подсчёты, получение карточки и отчёта ничего не меняют и не отправляют уведомлений. Все методы, кроме `ConsoleNotifier.send`, возвращают результаты или меняют состояние без печати в консоль.
