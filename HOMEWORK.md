333# Пробная домашняя работа

Это небольшое задание для проверки сдачи через pull request.

В файле [Solution.kt](homework/src/main/kotlin/homework/Solution.kt) реализуйте функцию `sum(a: Int, b: Int): Int`, которая возвращает сумму двух целых чисел.
Оба аргумента находятся в диапазоне от −1 000 000 до 1 000 000 включительно.
Например, `sum(2, 3)` возвращает `5`.

Сохраните `package homework` и сигнатуру функции. Не читайте ввод и не печатайте ответ.
В пробном задании всё решение должно находиться в этом файле.

## Сдача

1. Перед решением создайте отдельную ветку в терминале IDEA: `git switch -c homework`.
2. Отправьте решение в свой форк:

   ```shell
   git add homework/src/main/kotlin/homework/Solution.kt
   git commit -m "Solve homework"
   git push -u origin homework
   ```

3. На GitHub в своём форке выберите ветку `homework` и нажмите **Contribute → Open pull request**.
4. Репозиторий назначения — `Slava-ne-Merlow/seminar-3-fd`, ветка — `main`. Нажмите **Create pull request**.
5. Дождитесь результата **Домашняя работа / проверка** в списке проверок PR. Там будет число пройденных проверок.
6. Если нужно исправление, измените файл и сделайте новый commit и push в ту же ветку. Новый PR создавать не нужно.

Тесты хранятся отдельно. Для сдачи не меняйте тесты, настройки Gradle и workflows: итоговая проверка использует только файл решения.
В ветке `homework` и для PR запускается только проверка домашки. Семинар проверяется при push в `main`. Объединять PR самостоятельно не нужно.
