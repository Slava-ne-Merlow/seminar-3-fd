Для экспериментов есть [Main.kt](src/main/kotlin/Main.kt): импортируйте функции и классы из заданий, вызывайте их и смотрите вывод. Запуск — зелёная кнопка рядом с `main` в IDEA. Вызов функции с незаполненным `TODO` завершится ошибкой.

## Как проверить решение

Откройте **Terminal** в IDEA в папке проекта.
Для задачи 01 выполните три команды по очереди:

```shell
git add task01/src/main/kotlin
git commit -m "Solve task01"
git push -u origin main
```

- `git add` — подготовить файлы решения к коммиту.
- `git commit` — сохранить изменения на компьютере.
- `git push` — отправить их в свой форк на GitHub.

Для другой задачи замените `task01` на её номер, например `task02`.
После исправления решения повторите те же три команды.

Если Git просит указать автора, подставьте своё имя и email, затем повторите команды выше:

```shell
git config user.name "Ваше имя"
git config user.email "your-email@example.com"
```

В своём форке откройте **Actions**. Если видите кнопку **I understand my workflows, go ahead and enable them**, нажмите её **до первого push**.

После push откройте **Actions → Проверка заданий → последний запуск → нужная задача → Показать результаты**.
Дождитесь результата. Если есть ошибки, исправьте код и отправьте его снова.

Смотрите на результат своей задачи: остальные могут быть красными, пока вы их не решили.
Если команда выдаёт непонятную ошибку, позовите преподавателя.
